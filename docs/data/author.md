# Author

**Spec version:** 1

> Conventions (uid, script codes, types) are in [`README.md`](README.md).

## Purpose

An `Author` is the ācārya / composer of one or more [Songs](song.md). Songs reference an author by
`uid`; the Authors screen lists authors and their songs.

## Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `uid` | string | yes | Stable identifier, e.g. `"ldt"`, `"bt"`. `"?"` is the reserved sentinel for unknown authorship. |
| `names` | list<ScriptText> | yes | The author's name across scripts (`{ scriptCode, text }`). At least one. |
| `bio` | list<string> | no | Optional short biography lines. |

## Invariants

- `uid` is unique and immutable.
- The sentinel author `"?"` always exists, with a display name meaning "unknown", so unattributed
  songs still resolve.
- Every song's `authorUid` resolves to an `Author` (or `"?"`).

## Example

```jsonc
{ "uid": "ldt", "names": [{ "scriptCode": "Beng", "text": "শ্রীল লোচন দাস ঠাকুর" },
                          { "scriptCode": "Latn", "text": "Śrīla Locana Dāsa Ṭhākura" }] }
```

## Platform notes

- **No standalone authors dataset ships.** The corpus provides only per-song `author_uid` +
  `author_display`; each platform **derives** the Author catalog at runtime by scanning the songs
  (one representative per distinct `author_uid`). This is the required approach, not a shortcut.
- Real-corpus caveat: ~half of `author_uid` values are short codes (e.g. `ldt`); the other half use
  the author's full native-script name *as* the `author_uid`. Either way, `author_display` is now
  **always populated** (see below), so the empty-`author_display`→`author_uid` fallback is a
  belt-and-suspenders path rather than a common case.
- **Romanization ships.** `author_display` carries a native (`Beng`/`Deva`) entry **and** a `Latn`
  IAST entry for every one of the 84 distinct authors, generated by
  `pipeline/fix_author_display.py` (Aksharamukha draft + curated Gaudiya-convention map).
  Author names therefore honor the reader's script setting on every surface (song header, authors
  list, song-list rows, player) via `pickScriptText(names, [listLanguage/displayScript, 'Latn',
  'Beng'])`.
- Consistency: no dangling `author_uid`s — every song's author resolves within the derived catalog.
