# Skills

## todolist
When the user asks to add, update, remove, or view todo items, read and edit the `todolist.md` file in the project root. Follow these rules:

- **View**: Read `todolist.md` and display the current items
- **Add**: Append new items under the appropriate section with `- [ ]` checkbox syntax
- **Complete**: Change `- [ ]` to `- [x]` for the specified item
- **Remove**: Delete the specified item line
- **Prioritize**: Items are ordered by priority within each section (highest first)

Each item should follow this format:
```
- [ ] **Title** — Description
```

Sections group items by feature area or milestone. Keep the file clean and up to date.
